Este projeto é uma app móvel React Native (Expo). O preview do Lovable só consegue mostrar apps web, por isso aqui aparece esta página em vez da app.

Para testares a app a sério:

  1. Instala Expo Go no telemóvel.
  2. Clona o repositório e corre pnpm install.
  3. Inicia com pnpm dev:metro e lê o QR code.
